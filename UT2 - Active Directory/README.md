# Active Directory
En esta unidad, hemos realizado tareas sobre **Active Directory** en **Windows Server 2025**, en el que se han hecho cosas como:
- Creación de dominios
- Promoción de servidores a **Controlador de dominio**
- Unión de clientes en Windows 11 al dominio
- Extraer el script que se crea al crear un dominio
- Uso de un router **pfSense** para simular un entorno real
- Configuración de reenviadores DNS
- Crear un segundo servidor y promocionarlo como segundo controlador de dominio
- Replicar un controlador de dominio en otro
- Compartición de carpetas en red
- Creación de usuarios y grupos en el dominio
- Directorio con los archivos del trabajo grupal.
